# Avijit Chakraborty — Portfolio V2

A recruiter-focused, responsive static portfolio for GitHub Pages.

## Included
- `index.html` — complete portfolio
- `styles.css` — responsive design, dark mode and mobile layout
- `script.js` — theme and scroll animations
- `assets/profile.png` — supplied professional photo
- `assets/og-image.jpg` — LinkedIn/social sharing preview
- `assets/favicon.svg` — custom favicon
- `Avijit_Chakraborty_CV.docx` — downloadable CV

## Important
The LinkedIn button currently points to the generic LinkedIn homepage because the exact profile URL was not provided. Replace the `https://www.linkedin.com/` link in `index.html` with the actual profile URL before publishing.

The portfolio content is based on the supplied CV. Case studies describe documented responsibilities and do not invent performance metrics.

## GitHub Pages
Put all files/folders in the repository root, especially `index.html`, and publish from `main` / root.
